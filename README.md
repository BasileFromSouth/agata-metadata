# 📢 Agata - Public Releases

This repository is dedicated to the distribution of updates and metadata management for the **Agata** application.

### 🚀 Download
To get the latest stable version of Agata, please visit the [Releases](https://github.com/BasileFromSouth/agata-metadata/releases) section.

### ℹ️ About Agata
Agata is a minimalist writing assistant that uses AI to instantly correct, improve, and translate your text via global keyboard shortcuts.

*Note: The application's source code is hosted in a private repository for security and intellectual property reasons.*
